# 슈퍼로봇대전 F 세가 새턴 한국어화 v1.2

[v1.2 다운로드](https://github.com/geesekim/ss-srwf-korean-patch/releases/tag/v1.2) · [적용 안내](output/1.2/적용안내.txt)

## 수정 사항

- ‘아니오’로 전투를 진행한 뒤 전술맵 메뉴의 배경과 테두리가 사라지거나 메뉴 색상이 바뀌는 문제를 수정했습니다.
- 적 페이즈에서 ‘아니오’를 선택했을 때 HP 글자와 피해량 숫자가 좌우로 뒤집히는 문제를 수정했습니다.
- 전술맵의 전투 효과 문구가 주변 기체에 가려지는 문제를 수정했습니다.

## 추가된 기능

- 적 페이즈에 공격받았을 때도 대응을 확정한 뒤 ‘전투연출표시’에서 ‘예’ 또는 ‘아니오’를 고를 수 있습니다. 같은 맵에서 직전에 확정한 선택이 기본으로 표시됩니다.
- 적 페이즈의 전투 화면에서도 B 버튼으로 연출을 건너뛰고 전술맵에서 결과를 확인할 수 있습니다.

# 슈퍼로봇대전 F 세가 새턴 한국어화 v1.1

[v1.1 다운로드](https://github.com/geesekim/ss-srwf-korean-patch/releases/tag/v1.1) · [적용 안내](output/1.1/적용안내.txt)

## 수정 사항

- 무기창의 크리티컬 보정치가 실제 전투 판정에 반영되도록 수정했습니다. 베어내기와 실드방어의 레벨 9 발동 확률 오류를 바로잡았습니다.
- 오라베기와 하이퍼오라베기의 공격력에 성전사 레벨당 200의 보정이 적용되도록 수정했습니다.
- 기체 고유 오라 배리어의 차단 한계에 성전사 레벨당 200을 더하도록 수정했습니다. 일반 전투와 맵병기의 빔 공격에 적용됩니다.
- 전투 화면의 크리티컬, 분신, 겟타비젼, 마하스페셜, 진겟타비젼과 빔코팅 등 배리어 효과 문구를 한글화했습니다.
- 특수능력과 강화파츠 설명의 ‘빔코트’를 ‘빔코팅’으로 통일하고, 특수능력 ‘진 겟타비젼’의 표기를 ‘진겟타비젼’으로 수정했습니다.
- 게임의 메인 타이틀 로고를 한글화했습니다.

## 추가된 기능

- 아군의 공격 대상을 고른 뒤 전투 예측창에서 ‘전투연출표시’를 ‘예’ 또는 ‘아니오’로 설정할 수 있습니다. 같은 맵에서 다음 전투 예측창을 열면 직전에 확정한 선택이 기본값으로 표시됩니다.
- ‘아니오’를 선택하거나 전투 화면에서 B 버튼을 누르면 전술맵에서 결과를 확인할 수 있습니다. 공격 결과가 먼저 나오고, 반격이 있으면 이어서 나옵니다. 대상 기체 위에 효과 문구가 나타났다가 사라진 뒤 HP 게이지와 피해량이 차례로 표시됩니다.
- 전술맵 결과에는 크리티컬, 특수 회피, 배리어, 실드방어, 베어내기 등 실제로 발동한 효과가 표시됩니다. 일반 명중과 회피는 각각 `HIT`와 `MISS`로 표시됩니다.

# 슈퍼로봇대전 F 세가 새턴 한국어화 1.0

세가 새턴 일본판 **Super Robot Taisen F V2.002**(제품 번호 `T-20610G`)를 대상으로 한 한국어 패치입니다. [Release 다운로드](https://github.com/geesekim/ss-srwf-korean-patch/releases/tag/v1.0) · [xdelta 패치](output/1.0/SRWF_KO_1.0.xdelta) · [적용 안내](output/1.0/적용안내.txt) · [동봉 파일](output/1.0)

## 작업 범위

- 프롤로그·시나리오 이벤트·전투·패배·저장 후 중단 대사를 한국어로 적용했습니다.
- 유닛·인물·무기·정신 커맨드·강화파츠의 명칭과 설명, 도감 및 주요 메뉴·설정·저장 화면을 한국어로 적용했습니다.
- 타이틀 메뉴, 시나리오 제목, 등장 작품명과 데모 선택 화면의 이미지 문구를 한국어로 교체했습니다.
- 주인공의 이름·성·애칭을 한글로 입력하고 저장·불러오기 할 수 있도록 수정했습니다.

현재 적용 범위를 정리한 문서이며, 전체 게임의 모든 문구와 화면에 대한 실행 검증이 완료된 것은 아닙니다.

## 사용 폰트

- **Galmuri11**: 대사와 일반 메뉴 등 한글 본문.
- **Galmuri9**: 타이틀 메뉴.
- **본명조 Regular(Source Han Serif K)**: 시나리오 제목 이미지.

[Galmuri](https://github.com/quiple/galmuri)는 SIL Open Font License 1.1에 따라 사용하며 패치에 라이선스 문서를 동봉합니다. 본명조도 SIL Open Font License 1.1에 따라 사용하며, 두 폰트의 라이선스 문서를 동봉합니다. 폰트 파일은 배포하지 않습니다.

## 원본과 달라진 부분

- 일본어 글리프와 이미지 문구를 한글로 교체하고, 한글 표시·이름 입력을 위한 처리를 추가했습니다.
- 번역문 길이에 맞춰 일부 표시 영역·라벨·선택 강조의 크기와 위치를 조정했습니다. 대사 줄바꿈은 어절과 이름을 보존하면서 표시 영역을 활용하도록 재배치했습니다.
- 인물의 말투를 반영해 대사를 다듬었으며, 텍사스 맥의 영어식 표현은 영어 또는 한글 음차로 옮겼습니다.
- 확장된 번역·글리프 데이터를 담기 위해 데이터 트랙을 추가했습니다. 패치 결과를 실행할 때는 동봉한 CUE를 사용해야 합니다.
