# 슈퍼로봇대전 F 세가 새턴 한국어화 1.0

세가 새턴 일본판 **Super Robot Taisen F V2.002**(제품 번호 `T-20610G`)를 대상으로 한 한국어 패치입니다. [Release 다운로드](https://github.com/geesekim/ss-srwf-korean-patch/releases/tag/v1.0) · [xdelta 패치](output/1.0/SRWF_KO_1.0.xdelta) · [적용 안내](output/1.0/적용안내.txt) · [동봉 파일](output/1.0)

## 작업 범위

- 프롤로그·시나리오 이벤트·전투·패배·저장 후 중단 대사를 한국어로 적용했습니다.
- 유닛·인물·무기·정신 커맨드·강화파츠의 명칭과 설명, 도감 및 주요 메뉴·설정·저장 화면을 한국어로 적용했습니다.
- 타이틀 메뉴, 시나리오 제목, 등장 작품명과 데모 선택 화면의 이미지 문구를 한국어로 교체했습니다.
- 주인공의 이름·성·애칭을 한글로 입력하고 저장·불러오기 할 수 있도록 수정했습니다.

현재 적용 범위를 정리한 문서이며, 전체 게임의 모든 문구와 화면에 대한 실행 검증이 완료된 것은 아닙니다.

## 사용 폰트

- **Galmuri11**: 대사와 일반 메뉴 등 한글 본문.
- **Galmuri9**: 타이틀 메뉴.
- **본명조 Regular(Source Han Serif K)**: 시나리오 제목 이미지.

[Galmuri](https://github.com/quiple/galmuri)는 SIL Open Font License 1.1에 따라 사용하며 패치에 라이선스 문서를 동봉합니다. 본명조도 SIL Open Font License 1.1에 따라 사용하며, 두 폰트의 라이선스 문서를 동봉합니다. 폰트 파일은 배포하지 않습니다.

## 원본과 달라진 부분

- 일본어 글리프와 이미지 문구를 한글로 교체하고, 한글 표시·이름 입력을 위한 처리를 추가했습니다.
- 번역문 길이에 맞춰 일부 표시 영역·라벨·선택 강조의 크기와 위치를 조정했습니다. 대사 줄바꿈은 어절과 이름을 보존하면서 표시 영역을 활용하도록 재배치했습니다.
- 인물의 말투를 반영해 대사를 다듬었으며, 텍사스 맥의 영어식 표현은 영어 또는 한글 음차로 옮겼습니다.
- 확장된 번역·글리프 데이터를 담기 위해 데이터 트랙을 추가했습니다. 패치 결과를 실행할 때는 동봉한 CUE를 사용해야 합니다.
